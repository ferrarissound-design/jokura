# jokura

ジョークラは、ブラウザで遊べるボクセルサバイバルゲームです。素材を集めて装備をクラフトし、WAVEを耐え抜き、WAVE20のキングダイヤモンドドラゴン討伐を目指します。

## ゲームモード

タイトル画面の `🎮 MODE` ボタンで、サバイバル / クリエイティブを切り替えてから `NEW GAME` で開始します。モードはセーブスロットごとに保存されます。

- **⚔ サバイバル**: 通常モード。素材集め・クラフト・WAVE防衛でクリアを目指します。
- **🪄 クリエイティブ**: 本家マイクラ風の建築モード。
  - 無敵（ダメージ・溶岩・寒冷・空腹なし）
  - ブロック・矢は無限、クラフトも素材不要、全武器解放
  - ブロックは即時破壊（溶岩岩なども破壊可能）
  - 敵WAVE・ボス・地下敵は出現しない
  - 飛行可能 — PC: `Space` 2回押しで切替、`Space` 上昇 / `Shift` 下降。スマホ: `🕊 FLY` ボタンで切替、`JUMP` 上昇 / `⬇ DOWN` 下降。降下して着地すると飛行解除。
  - スコアランキング・実績には記録されません

## 遊び方

1. 木や石などのブロックを壊して素材を集めます。
2. `CRAFT` から剣・ハンマー・弓・ベッド・チェストなどを作ります。
3. 夜やWAVEで出現する敵を倒してスコアを稼ぎます。
4. 鎧をクラフトして敵の攻撃に備えます。
5. 豚・羊・鶏を育てて肉・ウール・卵を集め、畑で小麦も育てます。
6. 地下で鉄鉱石を掘り、かまどで鉄インゴットに精錬して鉄装備を整えます。
7. さらに深くでダイヤや宝箱を探し、ダイヤ装備を作ります。
8. WAVE20で出現するキングダイヤモンドドラゴンを倒すとクリアです。

## 防具（鎧）

`CRAFT` から鎧を作ると敵の攻撃ダメージを軽減できます。

| 鎧 | 素材 | 軽減率 | 耐久 |
| --- | --- | --- | --- |
| 🛡 木の鎧 | 🪵×8 + 🌿×4 | 20% | 60 |
| 🛡 石の鎧（要ハンマー） | 🪨×15 + 🪵×5 | 35% | 120 |
| 🔩 鉄の鎧（要ハンマー） | 🔩×5 | 45% | 180 |
| 💎 ダイヤの鎧 | 💎×4 + 🪨×10 | 55% | 250 |

- ダメージを防ぐたびに耐久が減り、0になると壊れます。
- 同じ鎧を再クラフトすると修理（耐久全回復）できます。
- 溶岩・寒冷・空腹のダメージには効果がありません。
- 装備中の鎧と耐久は画面左上に表示され、セーブにも保存されます。

## 鉄鉱石・精錬

地下の深さ13あたりから🔶鉄鉱石を採掘できます。鉄鉱石はそのままでは装備に使えないため、🪨石×12で🔥かまどをクラフトして設置し、近くで `CRAFT` を開いて精錬します。

- 🔶鉄鉱石×1 + 🪵木×1 → 🔩鉄インゴット×1
- 🔩鉄の剣: 🔩鉄インゴット×3 + 🪵木×1
- 🔩鉄の鎧: 🔩鉄インゴット×5

鉄装備は石装備とダイヤ装備の中間の強さです。ダイヤが足りない段階のWAVE攻略に役立ちます。

## 動物・牧畜

ワールドには🐷豚・🐑羊・🐔鶏が生息しています。

- **🐷 豚**: 倒すと🥩肉がもらえます。
- **🐑 羊**: 近づいて `X`キー（スマホは`PLACE`長押し）で毛を刈ると、倒さずに🧶ウールが手に入ります。刈った毛はしばらくすると生え変わります。倒すと肉とウールの両方が手に入ります。
- **🐔 鶏**: 時々🥚卵を産み落とします。歩いて拾うと満腹度が回復します。倒すと肉がもらえます。

## 農業

1. 🌿草×3で `CRAFT` から🌱種をクラフトします。
2. 草ブロックの上を見て `X`キー（スマホは`PLACE`長押し）で種を植えます。
3. 時間とともに育ち、成熟すると同じ操作で収穫できます（🌾小麦2〜4個、時々🌱種も追加で入手）。収穫すると畑は消えるので、また植え直します。
4. 🌾小麦×4で `CRAFT` から🍞パンを作ると、満腹度とHPを回復できます。
5. 育てた畑はセーブデータに保存されます。

## 操作方法

### PC

- `WASD` / 矢印キー: 移動
- マウス: 視点操作
- 左クリック: 攻撃 / ブロック破壊
- 右クリック: ブロック設置
- `Space`: ジャンプ
- `Shift`: ダッシュ
- `E`: 武器切替
- `1`〜`8`: 設置ブロック切替
- `C`: クラフト
- `X`: チェスト・ベッドなどの家具操作 / 羊の毛刈り / 種植え・小麦収穫
- `B`: ベッド操作
- `F5`: セーブ

### スマホ / タブレット

- 左スティック: 移動
- 右側スワイプ: 視点操作
- `ATTACK`: 攻撃 / ブロック破壊
- `PLACE`: ブロック設置
- `PLACE` 長押し: ベッド・チェスト・地下宝箱の操作 / 羊の毛刈り / 種植え・小麦収穫
- `WEAPON`: 武器切替
- `CRAFT`: クラフトメニュー
- `💾`: セーブ

## 改善された遊びやすさ

- タイトル画面の `HOW TO PLAY` からゲーム内ヘルプを確認できます。
- `SETTINGS` から BGM / SE のミュートを切り替えられます。
- 画面左上に現在のおすすめ目標が表示されます。
- タイトル画面に最高スコアとローカルランキングが表示されます。
- セーブスロットから3つの保存データを選んで遊べます。
- 実績を達成すると素材・スコア・回復などの報酬を獲得できます。

## 実績

剣・ハンマー・弓・鎧のクラフト、拠点設置、羊の毛刈り、小麦の収穫、ダイヤ発見、地下宝箱、WAVE到達、ボス討伐などで実績が解除されます。実績は選択中のセーブスロットごとに保存され、タイトル画面の `ACHIEVEMENTS` から確認できます。

## セーブ

ゲーム内の `💾` ボタン、ポーズメニュー、または `F5` キーで、現在選択中のセーブスロットに保存できます。タイトル画面の `セーブスロット` から3つのスロットを選択・ロード・新規作成・削除できます。保存済みスロットで新しく始める場合は、上書き確認が表示されます。保存データと設定はブラウザのローカルストレージに保存されます。

## 起動方法

静的ファイルとして配信できます。ローカル確認例:

```bash
python3 -m http.server 4173
```

その後、ブラウザで `http://127.0.0.1:4173/` を開きます。
