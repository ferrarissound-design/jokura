# ジョークラ (jokura)

Three.js で作られた、ブラウザで遊べるボクセル系サバイバルゲームです。  
モバイル（タッチ操作）と PC（キーボード・マウス）両対応です。

## 遊び方

- ワールドで素材を集める
- 敵を倒してスコアとドロップを獲得する
- 武器を切り替えながら WAVE を生き残る
- 最終的に **WAVE20 のキングダイヤモンドドラゴン**討伐を目指す

## 操作方法

### PC

- `WASD` / 矢印キー: 移動
- マウス: 視点
- 左クリック: 攻撃
- 右クリック: 設置
- `Space`: ジャンプ
- `E`: 武器切替
- `1-5`: ブロック選択
- `Shift`: ダッシュ
- `F5`: セーブ
- `X`: 家具
- `B`: ベッド
- `C`: クラフト

### モバイル

- 左スティック: 移動
- 右スワイプ: 視点
- `⛏ ATTACK`: 攻撃
- `🧱 PLACE`: 設置（長押しで家具）
- `↑ JUMP`: ジャンプ
- `🔄 WEAPON`: 武器切替

## 実行方法

このリポジトリは静的ファイルのみで構成されています。

### 方法1: ファイルを直接開く

`index.html` をブラウザで開くだけで動作します。

### 方法2: ローカルサーバーで開く（推奨）

```bash
python -m http.server 8000
```

その後、`http://localhost:8000` を開いてください。

## ファイル構成

- `index.html`: 画面構造（HTML）
- `styles.css`: UIスタイル（CSS）
- `game.js`: ゲームロジック（JavaScript）

## メモ

- Three.js は CDN から読み込みます。
- セーブデータはブラウザのストレージを使用します。
