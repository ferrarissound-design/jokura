# jokura

ジョークラは、ブラウザで遊べるボクセルサバイバルゲームです。素材を集めて装備をクラフトし、WAVEを耐え抜き、WAVE20のキングダイヤモンドドラゴン討伐を目指します。

## ゲームモード

タイトル画面の `🎮 MODE` ボタンで、サバイバル / クリエイティブを切り替えてから `NEW GAME` で開始します。モードはセーブスロットごとに保存されます。

- **⚔ サバイバル**: 通常モード。素材集め・クラフト・WAVE防衛でクリアを目指します。
- **🪄 クリエイティブ**: 本家マイクラ風の建築モード。
  - 無敵（ダメージ・溶岩・寒冷・空腹なし）
  - ブロック・矢は無限、クラフトも素材不要、全武器解放
  - ブロックは即時破壊（溶岩岩なども破壊可能）
  - 敵WAVE・ボス・地下敵は出現しない
  - 飛行可能 — PC: `Space` 2回押しで切替、`Space` 上昇 / `Shift` 下降。スマホ: `🕊 FLY` ボタンで切替、`JUMP` 上昇 / `⬇ DOWN` 下降。降下して着地すると飛行解除。
  - `🏗 特殊生成` ボタン（💾の左隣）— 押すとメニューが開き、「🏔 賢者の樹庭」（岩の尖塔アーチ＋巨木＋池）、「🗼 プレアデス監視塔」（細い塔＋らせん階段＋頂上の神殿）、「🏝 空中神殿」（空に浮かぶ島＋八角神殿＋滝と浮遊岩）、「🌳 世界樹」（高さ約80〜110の巨大な樹＋中空の幹の螺旋階段・祭壇・展望台＋放射状の根＋垂れる蔦＋精霊の泉）、「🦴 眠れる石神」（地面に倒れて石化・風化した超巨大な人型の神。中空の頭蓋骨＋外へ膨らむ肋骨のホール＋節のある背骨＋左右で姿勢の違う腕と5本指の手＋脚＋胸の「古代の心核」＋そばに突き刺さる巨大武器〈剣/斧/槍〉。目・口・後頭部のひび・肋骨の隙間・胸の割れ目・手のひらから内部を探索でき、宝箱と敵が配置される）、「🏰 逆さ城」（空中に浮かぶ暗黒の逆さ城。下向きの尖塔・浮遊島・魔力コア）、「⏳ 時間が止まった村」（襲撃のまっただ中で時間停止した村。空中で静止した矢・崩れる途中の屋根・浮遊瓦礫・凍りついた水流・停止した敵を探索でき、中央の時間結晶を壊すと揺れ→発光→結晶片→矢→水→敵→瓦礫→強敵の順に段階的に時が動き出して襲撃が再開される。結晶を壊す前に罠や壁で備えるのが攻略のカギ）をワンクリック生成できます。押すたびに形・向き・欠損が変わり、セーブにも保存されます（サバイバルではチートパネルから使用可）。世界樹・眠れる石神は巨大なため生成をフレーム分割し、生成中は進捗表示が出て、生成前に確認ダイアログが表示されます。
  - `🗝 自動生成ダンジョン` — 5×5の部屋を毎回異なる迷路として生成します。宝箱・溶岩罠・敵を突破して最深部へ入ると扉が閉まり、専用ボス「迷宮の番人」が出現します。討伐すると出口と報酬宝箱が解放され、進行状況はセーブされます。
  - `▣ 範囲編集ツール`（💾の上あたりのボタン、PCは`V`キーでも開閉）— ブロックを2回タップして選んだ直方体範囲をまとめて編集できます。
  - 1回目のタップで🟩点A、2回目のタップで🟨点Bが決まり、以降のタップは点Bだけが動くので範囲を微調整できます（点Aをやり直すときは「🟩 点A」ボタンを押してからタップ）。
  - 「埋める / 壁 / 床 / 箱」はホットバーで選択中のブロックで生成されます（使うブロックはパネルに表示）。「削除」は範囲内を一括削除します。
  - `↩ Undo` で直近10回分まで編集を取り消せます。一度に編集できるのは10000ブロックまでです。
- スコアランキング・実績には記録されません

## 遊び方

1. 木や石などのブロックを壊して素材を集めます。
2. `CRAFT` から剣・ハンマー・弓・ベッド・チェストなどを作ります。
3. 夜やWAVEで出現する敵を倒してスコアを稼ぎます。
4. 鎧をクラフトして敵の攻撃に備えます。
5. 豚・羊・鶏を育てて肉・ウール・卵を集め、畑で小麦も育てます。
6. 地下で鉄鉱石を掘り、かまどで鉄インゴットに精錬して鉄装備を整えます。
7. さらに深くでダイヤや宝箱を探し、ダイヤ装備を作ります。
8. WAVE20で出現するキングダイヤモンドドラゴンを倒すとクリアです。

## 防具（鎧）

`CRAFT` から鎧を作ると敵の攻撃ダメージを軽減できます。

| 鎧 | 素材 | 軽減率 | 耐久 |
| --- | --- | --- | --- |
| 🛡 木の鎧 | 🪵×8 + 🌿×4 | 20% | 60 |
| 🛡 石の鎧（要ハンマー） | 🪨×15 + 🪵×5 | 35% | 120 |
| 🔩 鉄の鎧（要ハンマー） | 🔩×5 | 45% | 180 |
| 💎 ダイヤの鎧 | 💎×4 + 🪨×10 | 55% | 250 |

- ダメージを防ぐたびに耐久が減り、0になると壊れます。
- 同じ鎧を再クラフトすると修理（耐久全回復）できます。
- 溶岩・寒冷・空腹のダメージには効果がありません。
- 装備中の鎧と耐久は画面左上に表示され、セーブにも保存されます。

## 鉄鉱石・精錬

地下の深さ13あたりから🔶鉄鉱石を採掘できます。鉄鉱石はそのままでは装備に使えないため、🪨石×12で🔥かまどをクラフトして設置し、近くで `CRAFT` を開いて精錬します。

- 🔶鉄鉱石×1 + 🪵木×1 → 🔩鉄インゴット×1
- 🔩鉄の剣: 🔩鉄インゴット×3 + 🪵木×1
- 🔩鉄の鎧: 🔩鉄インゴット×5

鉄装備は石装備とダイヤ装備の中間の強さです。ダイヤが足りない段階のWAVE攻略に役立ちます。

## 調理・建築ブロック

かまどは鉄の精錬だけでなく、調理やガラス作りにも使えます。近くで `CRAFT` を開くと「🔥 精錬」「🍖 調理」メニューが表示されます。

- **🍖 ステーキ**: 🥩肉×1 + 🪵木×1（燃料）→ 🍖ステーキ×1。生肉より回復量が多く（満腹度+60 / HP+25）、`EAT` ボタンでステーキがあれば優先して食べます。
- **🪟 ガラス**: 🏖砂×1 + 🪵木×1（燃料）→ 🪟ガラス×1。半透明の建材で、明かりを通す窓や温室が作れます。
- **🧶 ウールブロック**: 🧶ウール×2 → 🧶ウールブロック×4（`CRAFT` メニュー・かまど不要）。柔らかな見た目の建材です。

ガラスとウールブロックはホットバーの9・0番スロット（スマホはタップ）で選んで設置します。

## 動物・牧畜

ワールドには🐷豚・🐑羊・🐔鶏が生息しています。

- **🐷 豚**: 倒すと🥩肉がもらえます。
- **🐑 羊**: 近づいて `X`キー（スマホは`PLACE`長押し）で毛を刈ると、倒さずに🧶ウールが手に入ります。刈った毛はしばらくすると生え変わります。倒すと肉とウールの両方が手に入ります。
- **🐔 鶏**: 時々🥚卵を産み落とします。歩いて拾うと満腹度が回復します。倒すと肉がもらえます。

## 農業

1. 🌿草×3で `CRAFT` から🌱種をクラフトします。
2. 草ブロックの上を見て `X`キー（スマホは`PLACE`長押し）で種を植えます。
3. 時間とともに育ち、成熟すると同じ操作で収穫できます（🌾小麦2〜4個、時々🌱種も追加で入手）。収穫すると畑は消えるので、また植え直します。
4. 🌾小麦×4で `CRAFT` から🍞パンを作ると、満腹度とHPを回復できます。
5. 育てた畑はセーブデータに保存されます。

## 💣 爆発物・最終兵器

`CRAFT` から3種類の爆発物を作れます。いずれも爆発処理は専用システムで、破壊はフレーム分割されるためスマホでも動作します。

- **💣 TNT**: 🏖砂×4 + 🔶鉄鉱石×1。ホットバーの0番で設置し、右クリック（スマホはタップ）で起爆メニューを開いて点火/近接センサー化できます。⬛黒曜石は壊せません。
- **🌋 地殻貫通爆弾**: 💣×4 + 🔩×3 + ⬛×2。**飛行中のみ**空中投下できる二段爆弾。地表で大爆発したあと地下へ貫通し、深部で連鎖爆発して巨大な縦穴クレーターを掘ります。PCは `N`キー、スマホは 🌋 BOMB ボタン。
- **☢ ツァーリ・ボンバ（最終兵器）**: 🌋×2 + 💎×6 + ⬛×8 + 💠×1。ゲームバランスを無視した**ワールド破壊級の大規模災害イベント**。PCは `M`キー、スマホは ☢ TSAR ボタンで、**地面に設置**（前方に着地）または**飛行中に空中投下**します。着弾後に短い起爆演出（警告音・赤点滅）を挟み、`fuseTime`（初期2.5秒）後に起爆します。
  - **段階演出**: ①全画面の白い閃光 → ②爆心の消滅（黒曜石・液体・建築も含めて即消去）→ ③ノイズで縁が不規則な巨大クレーター（フレーム分割破壊）→ ④時間で半径が拡大するリング状衝撃波（ダメージ＋強ノックバック）→ ⑤余波（キノコ雲・立ち上る煙柱・遅延二次爆発・爆心リングのガラス化/黒曜石化）。
  - **全モンスター強制即死**: 消滅半径内の敵・ボス・ラスボスは、無敵/シールド/フェーズ移行/ダメージ上限/復活をすべて迂回して即死します（ドロップ・討伐数・ボスバー消去・クリア処理などの既存の死亡処理は正常に発火）。
  - クレーターは既存のワールド保存方式（`worldEdits`）に従うため、再読み込み後も残ります。
  - **誤使用防止**: 初期状態では「二段確認」（一度目は警告、受付時間内にもう一度で起動）。⚙ SETTINGS の「☢ ツァーリ・ボンバ」から確認のON/OFF、および爆発規模の「規模スケール（20〜3000%）」を変更できます。1000%=**MAXIMUM**・2000%=**CATASTROPHE**・3000%=**EXTINCTION**。EXTINCTIONを初めて選ぶと一度だけ短い警告が出ます。3000%起爆時は専用の `☢ EXTINCTION EVENT` / `REGIONAL TERRAIN DATA ERASED` 表示（既存の起爆シーケンス演出を流用）、キノコ雲の拡大・長寿命化、灰が降る演出、ミニマップ上の破壊領域の赤黒い円表示が追加されます。
  - **永久破壊領域（TsarBlastZones）**: 1000%を超える規模（2000%/3000%）では、爆心から数百〜数千ブロック級のクレーターが、その場ですべてのvoxelを生成・走査することなく実現されます。爆発の瞬間には「中心座標・消滅半径・完全破壊半径・クレーター深度・形状シード」など少数のパラメータだけを`TsarBlastZones`へ登録し（`scripts/game/tsar_bomba.js`）、実際の地形の彫り込みは**プレイヤーが後からその場所へ近づき、チャンクが生成される瞬間**に遅延適用されます（`scripts/game/world.js` の `generateChunk`/`generateUnderChunk`）。読み込み済みの範囲は既存のフレーム分割破壊（`TsarDestructionQueue`）が、未読み込みの範囲はチャンク生成時の遅延カービングが**同じ距離減衰の式**でクレーターを彫るため、境界に段差や継ぎ目ができません。
    - 爆発の瞬間に置かれていた地形・建築（`worldEdits`に記録済みの過去の設置/破壊も含む）は永久破壊領域の内側で消去されますが、**爆発後にクレーター内へ新しく置いたブロックは、チャンクの再読み込みやセーブ/ロードのたびに消えることはありません**（適用順: 基本地形・自動生成構造物 → 永久破壊領域のカービング → `worldEdits.placed` の再生、という順序で担保）。
    - 永久破壊領域はセーブデータへ保存され（`tsarZonesSaveState`/`tsarZonesLoadState`）、ロード後も未訪問だった範囲へ正しく復元されます。複数回ツァーリ・ボンバを使用した場合は領域が配列として複数保存され、重なった領域も正しく合成されます。セーブスロットごとに独立しており、NEW GAME・別スロットのロード・DELETEでは前のワールドの領域が混ざりません。
    - チャンク生成のたびに全領域を走査しないよう、領域は256×256ブロック単位の粗い索引（`_tsarZoneGrid`）へ登録され、生成中のチャンクと実際にバウンディングボックスが交差する領域だけを判定します。

## 地上構造物・宝の地図

ワールドの各地には、バイオームごとに異なる構造物が自動生成されます。中心には🗝金の宝箱があり、💎ダイヤ・🔩鉄インゴット・🏹矢などの豪華な報酬が入っています。

- **🏜 ピラミッド（砂漠）**: 宝は中心に埋まっています。砂を掘り進んで宝箱を探しましょう。
- **❄ イグルー（雪原）**: 雪のドーム。入口から中に入ると宝箱があります。
- **🌲 遺跡（森林・草原）**: 崩れたレンガの壁と石柱。中心に宝箱があります。

地下祭壇の宝箱からは、時々**🗺 宝の地図**が手に入ります。所持している間は画面上部にコンパスが表示され、最寄りの未発見の構造物の宝を指し示します。矢印を頼りに遠征し、目標の宝箱を開けると特大ボーナス（💎大量＋スコア）を獲得できます。

## 敵バリエーション

WAVEが進むと、通常のゾンビ・スケルトン・ゴーレムに加えて新しい敵が出現します。

- **💣 クリーパー（WAVE4〜）**: 近づくと点火音とともに白く点滅・膨張し、約1秒後に爆発してブロックを破壊します。点火中は動かないので、走って距離を取るか、近づかれる前に弓で倒しましょう（⬛黒曜石は壊されません）。
- **🕷 クモ（WAVE3〜）**: 素早く、壁をよじ登ります。高い壁だけでは拠点を守れません。
- **👻 ファントム（WAVE6〜の夜・満月の夜）**: 夜空から急降下する飛行敵。朝日を浴びると燃えて消滅します。

## ランダムイベント

プレイ中にまれに発生する環境イベントです。

- **🧙 行商人**: 一定間隔で近くに出現します。Xキー（スマホはPLACE長押し）で話しかけると交易パネルが開き、余った木材・石材などをダイヤや鉄インゴットなどのレア素材と交換できます（在庫は出現ごとにリセットされ、放っておくとしばらくして立ち去ります）。
- **☄ 隕石落下**: 地上にいると警告の光柱が出現し、数秒後に着弾します。直撃を受けるとダメージを受けますが、着弾地点には浅いクレーターができ、鉄鉱石やダイヤなどのレア素材が降ってきます。
- **🌕 満月の夜**: 夜が始まる瞬間にまれに発生します。敵の出現数が増えますが、キルスコアが2倍になりドロップ率も上がります。夜明けまで生き延びましょう。

## 操作方法

### PC

- `WASD` / 矢印キー: 移動
- マウス: 視点操作
- 左クリック: 攻撃 / ブロック破壊
- 右クリック: ブロック設置
- `Space`: ジャンプ
- `Shift`: ダッシュ
- `E`: 武器切替
- `1`〜`8`: 設置ブロック切替
- `C`: クラフト
- `I` / `Tab`: インベントリ（バッグ）開閉
- `X`: チェスト・ベッドなどの家具操作 / 羊の毛刈り / 種植え・小麦収穫
- `B`: ベッド操作
- `N`: 🌋 地殻貫通爆弾を投下（飛行中のみ）
- `M`: ☢ ツァーリ・ボンバを設置 / 空中投下
- `F5`: セーブ

### スマホ / タブレット

画面はゲーム世界を見やすくするため、必要な操作だけを配置しています。

- 左スティック（画面左下）: 移動（倒し切りでダッシュ）
- 右側スワイプ: 視点操作
- **メインアクション**（右下の大きなボタン）: 選択中の武器に応じて攻撃・採掘（`ATTACK` / 弓は `SHOOT` / 杖は `CAST` など）。アイコンとラベルは装備中の武器に連動して変化します。
- **サブアクション**（メインの左）: ブロック設置（`PLACE`）。長押しでベッド・チェスト・地下宝箱の操作 / 羊の毛刈り / 種植え・小麦収穫。
- `JUMP`（メインの上）: ジャンプ。クリエイティブ飛行中は長押しで上昇。
- `FLY` / `⬇`（少し上）: クリエイティブ時の飛行切替 / 下降。
- 武器ボタン（🗡）: 武器切替。
- **上部のアイコンメニュー**（右上）: 🎒バッグ（インベントリ）/ クエスト / クラフト / メニュー（⏸ ポーズ→セーブ・設定など）。
- **インベントリ（バッグ）**: 素材・ブロック・武器・食料・設備・特殊アイテムをタブ分けしたグリッドで確認・選択できます。以前は画面左に常時表示していた素材一覧はここへ移動しました。クリエイティブでは各アイテムに個数を表示せず、上部に `CREATIVE ∞` を1つだけ表示します。
- セーブはメニュー内、またはオートセーブで行われ、保存時は小さなトースト通知が出ます。

## 実績

剣・ハンマー・弓・鎧のクラフト、拠点設置、羊の毛刈り、小麦の収穫、ダイヤ発見、地下宝箱、WAVE到達、ボス討伐などで実績が解除されます。実績は選択中のセーブスロットごとに保存され、タイトル画面の `ACHIEVEMENTS` から確認できます。

## 🐞 チート（デバッグパネル）

ゲーム中にポーズ（画面右上の `⏸` ／ PCは `Esc`・`P`）してメニューの `🐞 CHEATS` を開くと、マイクラのコマンド（`/give`・`/tp`・`/time` など）に相当する操作を**ボタンで**実行できます。

- **🎁 アイテム**: 基本素材・ダイヤ・矢・鉄・建材・食料・家具などをまとめて付与。
- **⚔ 装備・強化**: 全武器解放、ダイヤ装備一式、鉄の剣、ダイヤの鎧、エンチャントMAX。
- **❤ プレイヤー**: HP・満腹度全回復、🛡無敵のON/OFF、SCORE加算。
- **🕐 時間・天気**: 昼／夜、晴れ／雨／雷雨、満月の夜。
- **🌊 WAVE・敵**: 次のWAVEへ、雑魚・クリーパー・クモ・ファントム・ボス・最終ボスの召喚。
- **🎲 イベント・移動**: 行商人を呼ぶ、隕石、地上へ／原点(0,0)へテレポート。

チート（アイテム付与・無敵・敵召喚など）を使ったランは、クリエイティブと同様に**ローカルランキングへ記録されません**（フェアプレイのため）。この状態はセーブにも保存されます。

## セーブ

ゲーム内の `💾` ボタン、ポーズメニュー、または `F5` キーで、現在選択中のセーブスロットに保存できます。タイトル画面の `セーブスロット` から3つのスロットを選択・ロード・新規作成・削除できます。保存済みスロットで新しく始める場合は、上書き確認が表示されます。保存データと設定はブラウザのローカルストレージに保存されます。

## 起動方法

静的ファイルとして配信できます。ローカル確認例:

```bash
python3 -m http.server 4173
```

その後、ブラウザで `http://127.0.0.1:4173/` を開きます。

## 開発

ゲーム本体は `scripts/game/*.js` に機能別分割されています。各ファイルは `index.html` の `PARTS` 配列の順序で `<script>` として読み込まれ、同一のグローバルスコープを共有します。ファイルを追加したら `PARTS` にも追加してください（載せ忘れは lint が検出します）。

```bash
npm install   # 初回のみ（ESLint）
npm run lint  # 全ファイルを実行時と同じ順序で連結して検査
```

lint は未定義グローバル参照（タイポ）・同名関数の二重定義・`PARTS` の載せ忘れを検出します。GitHub Actions でも PR ごとに自動実行されます。
