📘 HOW TO PLAY
目的: 素材を集めて装備を強化し、WAVE20のキングダイヤモンドドラゴンを倒そう。
序盤: 木を5個集めて剣を作る → 石を集めてハンマー/弓を作る → ベッドとチェストで拠点準備。
地下: 深く掘るとダイヤ・古い宝箱・地下ドラゴンに出会える。危険なら地上へ戻ろう。
PC: WASD移動 / マウス視点 / 左クリック攻撃 / 右クリック設置 / E武器切替 / Cクラフト / F5セーブ。
スマホ: 左スティック移動 / 右スワイプ視点 / ATTACK攻撃 / PLACE長押しで家具・宝箱操作。
