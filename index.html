📘 HOW TO PLAY

    

      目的: 素材を集めて装備を強化し、WAVE20のキングダイヤモンドドラゴンを倒そう。

      序盤: 木を5個集めて剣を作る → 石を集めてハンマー/弓を作る → ベッドとチェストで拠点準備。

      満腹度: 走る・跳ぶ・戦うと減る。60以下で自然回復が止まり、0になるとHPが徐々に減る（10未満にはならない）。🥩肉で回復。

      防具: 鎧をクラフトすると敵の攻撃を軽減（🛡木20%→🛡石35%→🔩鉄45%→💎ダイヤ55%）。防ぐたび耐久が減り、0で壊れる。再クラフトで修理。溶岩・寒冷・空腹には無効。

      🔥 精錬・調理: 地下(深さ13〜)で🔶鉄鉱石を掘り、🪨×12のかまどを設置。近くでクラフトを開くと「🔥精錬」「🍖調理」メニューが出る。鉄鉱石＋🪵木(燃料)で🔩鉄インゴット、🏖砂＋🪵木で🪟ガラス、🥩肉＋🪵木で🍖ステーキ(満腹度+60/HP+25・EATで優先して食べる)を作れる。

      🪟 建築ブロック: 🪟ガラス(半透明)と🧶ウールブロック(🧶×2→×4でクラフト)はホットバーの9・0番スロット(スマホはタップ)で選んで設置する。

      💣 TNT: TNTを選んで通常どおり設置。TNTを照準してF/左クリック/PLACEを押すと小型操作UIが開き、起爆・近接罠切替・範囲表示・回収ができる。TキーでTNTを選択。

      動物・牧畜: 🐷豚は倒すと🥩肉。🐑羊は近くでXキー(スマホはPLACE長押し)で刈ると倒さず🧶ウールが手に入り、しばらくすると毛が生え変わる。🐔鶏は時々🥚卵を産み落とし、拾うと満腹度が回復。

      🐺相棒: 野生のオオカミは🥩肉を持っていると寄ってくる。近くでXキー(スマホはPLACE長押し)で肉をあげると手なずけられ、付いてきて敵と戦ってくれる。倒れても時間か肉で復活。肉でHP回復。

      🐴騎乗: 野生のウマは🌾小麦を持っていると寄ってくる。近くでXキー(スマホはPLACE長押し)で小麦をあげると手なずけられ、もう一度Xで騎乗。移動速度アップ・ジャンプ強化・ダッシュの満腹度消費なし。降りるのもX。

      農業: 🌿草×3で🌱種をクラフトし、草ブロックの上を見てXキー(スマホはPLACE長押し)で植える。時間で育ち、成熟したら同じ操作で収穫（🌾小麦＋時々🌱種）。🌾小麦×4で🍞パンを作ると満腹度とHPを回復。

      🕷 新たな敵: 💣クリーパーは近づくと点火して爆発する(点火中は動かないので走って逃げろ)。🕷クモは壁をよじ登る。👻ファントムは夜に空から襲来し、朝日を浴びると燃えて消える。

      🌦 天気: 屋外で🌧雨/⛈雷雨に濡れていると🔥炎上ダメージの消化が早まる。❄雪原で⛈雷雨が重なると吹雪になり、移動速度低下・満腹度消費増加・寒冷ダメージ間隔短縮が起きる。⛈雷雨中は白い光の柱が落雷の予告。数秒後に直撃するので離れよう（プレイヤーだけでなく敵・ボスにも当たる）。

      バイオーム素材: 各バイオームに固有素材がある。🧊氷(❄雪原・上を歩くと滑る) / ⬛黒曜石(🌋火山・超硬い＆敵に壊されない) / 🔮水晶(🪨岩山) / 🌵サボテン(🏜砂漠) / 🍄キノコ(🌲森林) / 🟤粘土(🌿草原)。

      ⚒ 武器強化: 🪨×15＋💎×1で強化台をクラフトして設置。近くでクラフトメニューを開くと、余った💎ダイヤや💠ドラゴンコアで「攻撃+1」「射程+15%」「🔥炎上付与」「❄氷結付与」を付けられる。

      🏹 矢の切替: 🔥火矢(⬛黒曜石)と🧊氷矢(🧊氷)をクラフトしたら、Rキー(スマホは左のARROW表示をタップ)で装填する矢を切替。火矢は敵を燃やし、氷矢は鈍足にする。

      ♾ エンドレス: WAVE20クリア後はエンドレスモードに挑戦できる。難易度が上がり続ける無限WAVEでハイスコアを狙おう。5WAVEごとに強化ボスが出現。

      地下: 深く掘るとダイヤ・古い宝箱・地下ドラゴンに出会える。危険なら地上へ戻ろう。

      PC: WASD移動 / マウス視点 / 左クリック攻撃 / 右クリック設置 / E武器切替 / Cクラフト / F5セーブ。

      スマホ: 左スティック移動 / 右スワイプ視点 / ATTACK攻撃 / PLACE長押しで家具・宝箱操作。

      🐞 COMMAND: ゲーム中にポーズして「🐞 COMMAND」を開くと、アイテム付与・無敵・時間/天候変更・敵召喚・テレポートなどをボタンで実行できる（マイクラのコマンド相当）。使ったランはランキングに記録されない。

      クリエイティブ: タイトルの MODE で切替。無敵・ブロック無限・即時破壊・敵なしで自由に建築。飛行はPC: Space2回押し(Space上昇/Shift下降)、スマホ: FLYボタン(JUMP上昇/⬇下降)。
